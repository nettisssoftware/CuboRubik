# Zun Cube Simulator

Simulador web interactivo de cubo de Rubik 3×3 en 3D, desarrollado por Nettiss Software.

Permite girar las capas del cubo, personalizar colores y temas, ajustar controles y guardar el progreso localmente en el navegador.

## Tecnologías principales

- React y TypeScript
- Three.js y React Three Fiber
- TanStack Start y Vite
- Tailwind CSS y Zustand

Sitio: https://cuborubikgame.vercel.app
